# TangledLink 0.9.8-test

- Анимированные фоны Tangled Original, Sakura, Aurora и Cyberpunk на основе готовых иллюстраций.
- Новый Canvas-портал VPN: реальные состояния запуска/работы сервиса, мягкое свечение и пульсация. Проверка сервера не имитирует подключение.
- Движение останавливается при уходе с экрана, сворачивании, уменьшении эффектов, системном отключении анимаций и энергосбережении. При ошибке видео остаётся статичный фон.
- Основной playback — локальный MP4 через Media3. На эмуляторах используется Canvas-вариант из пакета для снижения стоимости программного декодирования.
- В Terminal (Linux) вторая вкладка теперь **«Консоль»**. Системная информация и события находятся внутри неё; список серверов доступен через карточку сервера и настройки.
- Выбранный сервер и трафик Terminal оформлены как TUI: консольные поля, RX/TX, символьный график и реальное время работы.
- Вход активированного аккаунта больше не зависит от доступности панели 3x-ui. Проверки подписки для конфигураций, активации и продления сохранены.
- Подготовлен безопасный deploy hook обновления сертификата подписок для 3x-ui 3.11.0.

Оформление: **Ещё → Темы оформления**. Выключение движения: **Уменьшить эффекты → Применить**.
Terminal сохраняет собственное оформление, без новых фоновых анимаций.

Проверки: PlaystoreDebug/PlaystoreRelease, JVM и backend-тесты. На Medium Phone прошли 23 UI-теста по этапам реализации: четыре видеопетли, fallback, lifecycle, состояния/доступность кнопки, палитры, компоновки и существующие действия. Проверены запуск/остановка существующего VPN-сервиса, поворот и смена темы без перезапуска его процесса.

Нагрузка на эмуляторе остаётся заметной. 60 FPS, энергопотребление и аппаратные декодеры физических телефонов не подтверждены. Запуск сервиса не считается доказательством доступности интернета.
