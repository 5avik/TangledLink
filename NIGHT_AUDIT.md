## Изменения

1. **Поиск терял видимое состояние при повороте.**
   Воспроизведение: открыть поиск, ввести TCP, повернуть экран.
   До исправления поле исчезало, но ViewModel продолжал фильтровать список.
   Теперь открытое поле и запрос сохраняются через rememberSaveable; восстановленный
   запрос снова передаётся существующему MainAction.Search при создании экрана.
   Проверено на эмуляторе: после поворота сохранён TCP и отображаются TCP-серверы.

2. **Слишком яркие подписи протоколов и задержки в светлой теме.**
   В списке серверов фиксированные неоновые цвета заменены семантическими цветами
   MaterialTheme: secondary для протокола, primary/error для задержки.
   Проверено визуально на главном экране в светлой и тёмной темах.
   Цвета следуют выбранной палитре, включая динамические цвета.
   Новых анимаций и фоновых задач не добавлено.

3. **Ранний запрос фокуса в диалоге авторизации.**
   Запрос фокуса перенесён внутрь содержимого AlertDialog, где уже создано поле.
   Добавлен TnglLoginDialogTest: фокус поля, ошибка пустого ввода, отсутствие callback
   при пустом вводе и передача обрезанного тестового токена.
   Тест вызывает только локальный callback; сетевого входа и выхода из аккаунта нет.

## Повтор запуска тестов из PowerShell

Только для текущего процесса, на отдельном эмуляторе без нужных данных.
connectedAndroidTest может удалить приложение и его данные после выполнения.
Не запускать такой прогон на личном телефоне.

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
$env:Path = 'C:\Program Files\Git\usr\bin;' + ($env:Path -replace '"','')
$env:ANDROID_SERIAL = 'emulator-5554'
.\gradlew.bat :app:testFdroidDebugUnitTest --no-daemon --console=plain
.\gradlew.bat :app:connectedFdroidDebugAndroidTest '-Pandroid.testInstrumentationRunnerArguments.class=com.v2ray.ang.ui.main.TnglLoginDialogTest' --no-daemon --console=plain
```
