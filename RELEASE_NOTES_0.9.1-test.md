# TangledLink 0.9.1-test

Тестовая версия из ветки test.

- Панель администрирования: список аккаунтов, выдача и перевыпуск кода, сброс пароля, завершение сессий.
- Отдельная служба tngl-admin и инструкция доступа через SSH-туннель или Nginx с HTTPS.
- Исправлена проверка подписок, содержащих дополнительные ссылки vpn://: приложение получает поддерживаемые VPN-конфигурации.
- Исправлено сравнение версий с суффиксом -test: стабильная 0.8 больше не предлагается вместо новой тестовой версии.
- Ядро с проверкой SHA-256 готовится до Gradle Sync и хранится вне build, сохраняясь после clean.

Package ID: pro.tngl. Version name: 0.9.1-test. APK version code: 4000010.

Это debug-APK для тестирования. Подпись CI может отличаться от локальной сборки и основной release-версии.
Не удаляйте установленное приложение без сохранения данных ради обхода несовпадения подписей.
Для большинства телефонов используйте arm64-v8a, при неизвестной архитектуре — universal.

Backend и панель устанавливаются отдельно из server/ по server/README.md.
Публичный доступ к панели требует HTTPS и ограничения запросов через Nginx; сам процесс слушает loopback.
Управление аккаунтом приложения не создаёт подписку в 3x-ui и не отзывает уже загруженные VPN-конфигурации.
Старый публичный маршрут подписок по ID требует отдельной защиты.

Полная активация на рабочем сервере, VPN и сохранение сессии после перезапуска требуют отдельной проверки с тестовым аккаунтом.
Автообновление тестовых выпусков пока не реализовано; этот пререлиз не публикуется как Latest.
