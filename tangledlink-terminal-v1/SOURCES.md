# Sources and provenance

Checked on 2026-11-16.

- Matrix Green: TangledLink adaptation of the prior conversation's concept. Secondary text accent lifted to `#BC96FF` for readable contrast.
- Catppuccin Mocha core colors: [official palette data](https://raw.githubusercontent.com/catppuccin/palette/main/palette.json), [project](https://github.com/catppuccin/palette). Material mappings and light companion roles are TangledLink adaptations.
- Tokyo Night core colors: [official Night variant](https://raw.githubusercontent.com/folke/tokyonight.nvim/main/lua/tokyonight/colors/night.lua) and [shared Storm colors](https://raw.githubusercontent.com/folke/tokyonight.nvim/main/lua/tokyonight/colors/storm.lua). TangledLink maps the colors to UI roles; this is not a copy of the theme's source code.
- Gruvbox core colors: [official palette definition](https://raw.githubusercontent.com/morhetz/gruvbox/master/colors/gruvbox.vim). Material roles and light companions are application adaptations.
- Font binaries: unmodified locally installed JetBrains Mono Nerd Font Regular/Bold from `ttf-jetbrains-mono-nerd-basic`; accompanying OFL copied from that same installed package. [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts). No font source is regenerated or renamed internally.
- Brand mark: same user-provided local TangledLink website resource reused in the four-theme package. No new logo generated.
- ASCII penguin miniature, grid backgrounds, SVG reference layouts, integration instructions, parser and palette model: prepared for this package. ASCII is an illustrative penguin motif, not an official Tux logo asset.
- UI references are deterministic SVG renders, not AI-generated screenshots or renders from Android. No external AI image generation was used for this addon.
