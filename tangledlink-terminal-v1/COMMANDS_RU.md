# Разрешённые команды

Это псевдоконсоль приложения. Parser не запускает системные команды и не выполняет ввод как код. Синтаксис ограничен одной командой, длина до 256 символов. Разделители — пробелы и табы. Переводы строк, управляющие символы и операторы оболочки отклоняются. Неизвестные команды не передаются дальше и не отражаются в логе.

| Ввод | Типизированный результат | Действие интегрирующего обработчика |
|---|---|---|
| `help` | Help | Локализованная помощь из whitelist |
| `connect` | Connect | Подключить через существующее действие, если не запущен и нет запроса |
| `disconnect` | Disconnect | Отключить через существующее действие, если запущен и нет запроса |
| `status` | Status | Показать реальное состояние сервиса; не обещать доступность интернета |
| `servers` | Servers | Текущий список и пригодные для выбора IDs, без адресов/конфигов/секретов |
| `server select <id>` | SelectServer(guid) | Повторно найти GUID в актуальном списке и отправить существующее действие выбора |
| `stats` | Stats | Текущие метрики либо «Нет данных» |
| `ping` | Ping | Существующая проверка текущего сервера; нет выбранного сервера — понятная ошибка |
| `clear` | Clear | Очистить только вывод консоли, не VPN-логи на диске |
| `theme` | ShowPalette | Показать активную terminal-палитру |
| `theme list` | ListPalettes | Четыре стабильных ID палитр |
| `theme set <palette>` | SetPalette(enum) | Сохранить terminal-палитру через текущий repository |
| `neofetch`, `fastfetch` | Neofetch | Открыть/показать системную карточку без shell |
| `about` | About | Версия и справка приложения |
| `sudo tangledlink connect` | Connect | Точный визуальный alias; не root |
| `sudo tangledlink disconnect` | Disconnect | Точный визуальный alias; не root |
| `sudo pacman -S freedom` | Freedom | Только текстовая пасхалка, без установки пакетов и сети |

ID палитр: `matrix_green`, `catppuccin_mocha`, `tokyo_night`, `gruvbox_dark`.

## Связь с реальными действиями

В проверенном исходном MainContract есть ToggleService. Нельзя безусловно переводить и Connect, и Disconnect в ToggleService: повторный connect выключил бы работающий VPN. Использовать `terminalConnectionIntent` как план, затем повторно проверить актуальное состояние и pending-gate в owning ViewModel перед отправкой текущего действия. Ручная кнопка и консоль должны делить этот gate, а не иметь два несогласованных флага.

В ожидании системного VPN-permission, обработки запроса или изменения состояния не выполнять дублирующий toggle. Снять pending на реальном результате/отмене/ошибке; не помечать Connected по таймауту. Если старая архитектура не даёт точного результата запроса, это нужно аккуратно обработать на уровне UI-событий, не переписывая сервис.

ID сервера parser сохраняет с исходным регистром. Синтаксический шаблон допускает до 128 буквенно-цифровых символов и `._:-`; это не доказательство существования ID. Если реальный проект использует другой формат доменного ID, адаптировать только эту валидацию с тестами; не переходить на видимые индексы.

Парсер возвращает коды ошибок, не готовые английские сообщения. Обработчик сопоставляет их со string resources. В пакете есть стартовые строки en/ru; все новые сообщения интеграции дополнительно локализуются.

## Ограничения основы

Parser, палитры и planner — реализованы и отдельно проверены. Обработчик с доступом к MainViewModel, навигация, pending-gate, история, autocomplete и persistence зависят от текущего проекта и должны быть интегрированы агентом. Объектов VPN-сервиса, root-процессов и сетевых клиентов в этой основе нет.
