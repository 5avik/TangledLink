# Проверка Terminal-пакета

Выполнено:

- Parser, enum, connection planner и palette model скомпилированы Kotlin 2.4.21 с JVM target 17; запуск на Java 21. Все 83 проверки пройдены, итоговая компиляция без предупреждений. Сводка — reference/core-check-result.txt.
- Проверки включают разрешённые команды, aliases, ошибки аргументов/палитры, неизвестные команды, ограничения длины, отклонение shell-синтаксиса/переводов строк/управляющих символов, fallback палитры и Connect/Disconnect во всех сочетаниях running/pending.
- Цветовые данные: 104 непрозрачные пары текста и фона прошли порог 4,5:1; минимальное рассчитанное значение 5.143:1. Это проверка данных, не реального Compose-рендера, alpha-слоёв или dynamic color. Особенности Gruvbox error marker описаны в design spec.
- Проверены валидность JSON, синтаксис resource XML, resource-имена, размеры всех WebP, SHA-256, сохранение того же фирменного знака.
- Fontconfig подтвердил наличие латиницы и всех русских букв с Ё/ё в обоих включённых шрифтах. OFL скопирована из того же установленного пакета.
- SVG-макеты отрендерены и визуально просмотрены: четыре палитры, главный экран, Console и Fetch. Это статичные макеты для интегрирующего агента.
- Ресурсных файлов: 15; исходный объём runtime-набора 5,278,831 байт. Основной объём занимают два локальных шрифта. Размер APK после сжатия/оптимизации здесь не измерялся.
- Проверено чистое рабочее дерево исходного Android-проекта; файлы в нём не менялись.

Not run — потребуется в Android-проекте после интеграции:

- Сборка Compose-экранов, APK, lint и обязательные проверки актуальных AGENTS.md.
- Command handler с существующим MainViewModel, атомарное взаимодействие общей кнопки/консоли и pending-gate, Android VPN-permission/cancel/failure.
- Сохранение пяти миров и четырёх terminal-палитр, Apply/Cancel, ошибка storage, recreation и перезапуск процесса.
- Реальные события, отбор безопасной диагностики и фактические источники метрик.
- Screen reader/TalkBack, semantics, D-pad, hardware keyboard, Tab/history, экранная клавиатура и IME insets.
- Контраст итогового UI, светлый/тёмный/system/dynamic, маленькие экраны, увеличенный текст и двухколоночный режим.
- Производительность и lifecycle декоративных анимаций.
- Настоящие VPN-подключение/отключение и переключение мира без перезапуска туннеля.

Не следует считать выполненными эти пункты по результатам статичных превью или JVM-проверок parser.
