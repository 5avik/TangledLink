# TangledLink 0.9.4-test

Тестовый выпуск Android-приложения и серверной части. Изменения относительно 0.9.3-test.

## Приложение
- Новый тёмный интерфейс в цветах TangledLink, фирменные шрифты и нижние вкладки: главная, серверы, подписка, ещё.
- Круглая кнопка VPN, логин над ней, поиск и фильтры серверов, избранное.
- Реальные загрузка/отдача, график активности и время подключения из VPN-движка.
- Адаптивная главная: компактные размеры, две колонки на широких окнах, прокрутка на маленьких экранах и плавающее меню.
- Обновлённый экран исключений приложений с сохранением настроек.
- Компактная карточка TangledLink Pro с мягким переливом; декоративная анимация останавливается в фоне и при отключённых системных анимациях.
- Тариф выбирается на странице подписки: 1/3/6/12 месяцев за 150/450/900/1800 ₽ (30/90/180/360 суток).
- Затем запрашивается только email для lava.top; после создания заказа автоматически открывается оплата через СБП.
- Возврат из браузера открывает вкладку подписки и проверяет реальный статус заказа. При ограничениях браузера доступна кнопка открытия приложения.

## Оплата и 3x-ui
- Интеграция lava.top с разовыми платежами PAY2ME/SBP, без автосписаний.
- Сервер сверяет платёж по Lava API, сумме, валюте, email покупателя и сохранённому ID инвойса.
- Заказ привязан к аккаунту из сессии; ID аккаунта должен точно совпадать с email клиента в 3x-ui.
- Email для оплаты используется отдельно и не меняет VPN-аккаунт.
- Подтверждённая оплата продлевает срок через API 3x-ui по email; UUID, subId и лимиты трафика сохраняются.
- Повторы webhook и неоднозначные тайм-ауты не начисляют дни повторно.
- Старые карточные счета сохраняют привязку при переходе на СБП; не оплачивайте одновременно старую и новую ссылку.
- Обновлены админка, документация настройки и диагностические инструменты. Секреты хранятся только на серверах.

## Проверка
Сборка и JVM-тесты Android, серверные тесты, проверки интерфейса на Medium Phone.
На Medium Phone подтверждён App Link app.tngl.pro, проверены переход из Chrome, холодный запуск и повторный возврат.
Поддельный status=success в ссылке не подтверждает оплату.
Реальная покупка с последующим продлением в production не выполнялась в рамках автоматической проверки.

## Установка
**Важно: 0.9.3-test из GitHub подписан временным CI debug-ключом. Этот выпуск использует постоянную release-подпись.**
Android не разрешит установку поверх того APK. Перед переустановкой сохраните настройки/профили и данные для входа:
удаление приложения удаляет локальные данные. Серверный аккаунт и срок подписки от переустановки не меняются.
Для следующих выпусков сохраняется эта постоянная подпись.

SHA-256 сертификата:
`24:4C:E8:07:99:7D:BD:E6:44:17:B1:2C:1F:50:86:EA:00:57:CD:C5:89:4B:D4:B9:AC:C2:24:2F:52:5C:86:C6`

APK: PlaystoreRelease, Android 7.0+ (API 24), versionCode base 13.
Для большинства современных телефонов подходит arm64-v8a; universal содержит все архитектуры.
Контрольные суммы файлов приложены в SHA256SUMS.txt.
Пререлиз не назначается Latest. Для возврата из браузера нужен новый APK и новый счёт Lava:
у ранее созданных счетов прежние параметры возврата.

Возвраты/чарджбэки требуют ручной обработки. Счета с неоднозначным созданием требуют сверки администратором.
Нет общей транзакции между SQLite и 3x-ui: одновременно не меняйте срок одного клиента другим биллингом.
