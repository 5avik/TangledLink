# TangledLink 0.9-test

Тестовая версия из ветки test.

- Вход по ID подписки и отдельному паролю приложения.
- Первая активация через одноразовый код.
- Смена пароля с завершением остальных сессий.
- Зашифрованное хранение токена с помощью Android Keystore.
- Backend авторизации для 3x-ui и инструкция установки.
- Автоматическая загрузка ядра с проверкой SHA-256.

## Установка

Для большинства современных телефонов выберите arm64-v8a.
Если архитектура неизвестна, используйте universal APK.
Для эмулятора x86_64 доступен отдельный APK.

Это debug-APK для тестирования, а не production-пакет.
Подпись отличается от основной release-версии; установить поверх неё такой APK
может быть невозможно. Debug-ключ CI также может отличаться от ключа локальной
тестовой установки. Не удаляйте основное приложение без сохранения нужных данных.

Package ID: pro.tngl. Version name: 0.9-test. APK version code: 4000009.
APK этой версии нельзя установить рядом с основной версией с тем же package ID.

## Авторизация

Нужен установленный backend на https://auth.tngl.pro:8443.
Для первой активации администратор выдаёт одноразовый код; пароль пользователь
задаёт самостоятельно. После активации используется ID подписки и пароль.

## Известные ограничения

- Полная активация, VPN-подключение и сохранение сессии требуют проверки на устройстве.
- Старый публичный адрес подписки доступен по ID до отдельной настройки его защиты.
- Отдельного тестового канала автообновлений пока нет.
- Этот релиз помечен Pre-release и не предлагается стандартным updater через /releases/latest.
