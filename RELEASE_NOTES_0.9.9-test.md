# TangledLink 0.9.9-test

- Подтверждение почты шестизначным кодом при регистрации и входе в аккаунты с привязанной почтой.
- Привязка почты в управлении аккаунтом; единый подтверждённый адрес для сайта и приложения.
- Вставка кода, таймер повторной отправки, ошибки неверного/просроченного кода и сети.
- Серверная защита прежних маршрутов входа и активации от обхода подтверждения.
- Самостоятельная регистрация, пробные 30 дней по отдельной кнопке и выдача стандартного набора серверов.
- Отдельный экран авторизации с анимированным фоном, обновлённые значки приложения/виджета/шторки и подписи серверов.

## Совместимость
Для аккаунтов без подтверждённой почты сохранён вход по паролю.
Старым APK для нового входа в аккаунт с подтверждённой почтой потребуется обновление. Действующие сессии сохраняются.
Пробный период выдаётся один раз на аккаунт; идентификатором VPN остаётся логин.
Установка поверх прежнего пререлиза возможна при совпадении подписи. Не удаляйте приложение ради обхода ошибки подписи без сохранения данных.

## Сборка и проверки
PlaystoreRelease; versionCode 18 (ABI APK code 4000018), постоянная release-подпись.
Серверные и Android-проверки описаны в EMAIL_VERIFICATION_REVIEW.md.
Почтовые сценарии автоматически проверялись с тестовым отправителем; настоящая доставка Gmail и полный TalkBack не подтверждены этими тестами.
