# Упрощение страницы подписки — 15 ноября 2026

Карточка TangledLink Pro содержит только название. Перелив рисуется в Canvas внутри скруглённой карточки.
Положение градиента читается в draw-фазе, без перестройки дерева каждый кадр.
Анимация существует только при RESUMED и включённых системных анимациях; в фоне фон статичен.

Выбор 1/3/6/12 месяцев остаётся только на странице подписки. 6 месяцев доступно за 900 ₽,
как в существующем продукте Lava. Выбранный срок явно передаётся через BeginBilling(months),
без ожидания асинхронного сохранения DataStore.
В диалоге нет повторного списка тарифов, инструкций или номера заказа.
Свежий заказ: email → «Оплатить» → создание заказа → один event открытия браузера.
Диалог с существующим pending-заказом позволяет повторно открыть прежнюю ссылку и проверить статус.
Загрузка, ошибки и статусы applying/retry/paid сохраняются; повторная проверка не открывает браузер.
События браузера принадлежат BillingController, Activity собирает их только при RESUMED;
отмена очищает неисполненное событие. Успешный redirect сам по себе не подтверждает платёж.

Для возврата после оплаты возможно добавить HTTPS App Links, assetlinks.json и successful_return_url Lava.
В текущем изменении автопереход из браузера обратно в приложение не реализован — пользователь запросил ответ о возможности.

Проверено: сборка и JVM-тесты прошли, 11 Compose-тестов на Medium Phone прошли (BillingDialogTest + PremiumDesignTest).
JVM-тесты контроллера (явный срок, одна навигация, ошибка/невалидный email без навигации).
Compose: сценарии главной, Pro без описания, выбор 6 месяцев, email с IME, pending без дублирующихся подсказок, busy/error.

Not run: TalkBack, полная матрица D-pad/клавиатуры и размеров/динамической палитры,
профилирование FPS/энергии, проверка системного уменьшения анимаций на устройстве,
реальная оплата из браузера и возврат по App Link. Production-платежи для проверки UI не создавались.
