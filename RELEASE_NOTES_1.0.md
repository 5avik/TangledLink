# TangledLink 1.0

- Регистрация с подтверждением почты, вход с кодом для аккаунтов с привязанным адресом и восстановление пароля.
- Пробный доступ на 30 дней и продление подписки в приложении.
- Пять тем оформления, включая Terminal, и анимация Neon Portal при входе.
- Обновлённые значки приложения, виджета и плитки быстрых настроек.

Для большинства современных телефонов подходит APK arm64-v8a. Если архитектура неизвестна, выберите universal. Для проверки загрузок приложен SHA256SUMS.
